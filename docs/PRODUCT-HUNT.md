## Current Positioning

**Tagline**

Turn scattered AI work into experience you can reuse.

**Description**

Wayfinder is a local macOS and Windows app that turns Codex and Claude Code
work into one visual voyage map. It automatically records prompts, responses,
tool activity, file changes, branches, failures, and decisions while keeping
the complete history on your computer.

Install Wayfinder once, continue working normally in your AI tools, then return
to the app to inspect how a project evolved across tools and attempts.
