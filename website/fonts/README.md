# Wayfinder Mobile Web Font

`wayfinder-sans-400.woff2` and `wayfinder-sans-700.woff2` are subsets of
Noto Sans SC v2.262 from Google Fonts. They contain only characters used by
the public website and are loaded only by the phone layout.

Noto Sans SC is distributed under the SIL Open Font License 1.1. See
`OFL.txt`.
