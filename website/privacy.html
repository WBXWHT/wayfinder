PRIVACY

数据边界

Wayfinder 的完整会话、代码快照和航海图保存在你的电脑上。

本地保存

Prompt、回复、工具摘要、验证结果和快照存储在 ~/.wayfinder。当前版本没有账号、遥测、广告或云同步。

自动采集

Wayfinder 在本机读取 Codex 与 Claude Code 保存的会话记录，并以增量方式更新航海图。它不抓取应用窗口，也不会把会话发送给 Wayfinder 服务。

规则分析

当前版本只在本地根据测试失败、工具失败、用户否决和回滚等明确证据整理失败候选，不调用云端模型。

网络访问

应用仅在你主动查看版本信息时打开 GitHub Releases。会话内容、代码快照和航迹不会随该操作上传。

删除数据

卸载应用不会删除历史。需要清除时，请先退出 Wayfinder，再删除 ~/.wayfinder 中对应项目或全部数据。
