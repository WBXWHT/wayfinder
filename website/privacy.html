PRIVACY

数据边界

Wayfinder 的完整会话、代码快照和航海图保存在你的电脑上。

本地保存

Prompt、回复、工具摘要、验证结果和快照存储在 ~/.wayfinder。当前版本没有账号、遥测、广告或云同步。

自动采集

只有用户连接并批准 Claude Code 或 Codex Hook 后，新会话才会被记录。Wayfinder 不导入安装前历史，也不扫描其他应用的私有数据库。

规则分析

当前版本只在本地根据测试失败、工具失败、用户否决和回滚等明确证据整理失败候选，不调用云端模型。

MCP 边界

主动调用 MCP 航海图时，宿主可能把工具结果交给它自己的模型服务。严格本地使用应通过 Wayfinder Companion 查看。
