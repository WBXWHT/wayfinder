WORKFLOW

照常使用 AI，Wayfinder 自动整理成图。

无需改变现有协作方式。当前版本会从 Codex 与 Claude Code 持续更新项目航海图。

  1. 01
    打开 Wayfinder

    桌面应用在后台读取新的本地会话记录。

  2. 02
    照常使用 AI 工具

    目标、回复、工具动作和文件变化自动归入对应项目。

  3. 03
    回看项目路径

    比较不同航程与分支，并回到原始会话和文件证据。

THE PATH BEHIND THE RESULT

不仅保留答案，也保留答案是怎么来的。

从第一次尝试，到排除错误方案，再到最终验证；已有证据会按实际记录连接到对应会话、文件变化或验证结果。

EVIDENCE, NOT VERDICTS

关键结论，都能回到相关过程记录。

会话、文件变化或验证记录会按实际可用情况保留；Wayfinder 不替你补造缺失证据。

正在推进

同一目标下，Codex 与 Claude Code 的尝试可以汇入一条航程。

验证失败

失败路线不会消失，测试、回滚与否决仍可追溯。

证据冲突

来源意见不一致时，保留各自证据，不替你编造结论。

TURN WORK INTO EXPERIENCE

项目结束后，解决问题的方法还在。

Wayfinder 把目标、尝试、失败和真实文件变更整理成一张本地航海图，让走过的弯路和验证过的方法都能被再次使用。
