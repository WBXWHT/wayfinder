EVIDENCE, NOT VERDICTS

每个结论，都能回到原始证据。

Wayfinder 展示过程，不替你编造一条过度整洁的成功故事。

正在推进

同一目标下，Codex 与 Claude Code 的尝试可以汇入一条航程。

验证失败

失败路线不会消失，测试、回滚与否决仍可追溯。

证据冲突

来源意见不一致时，保留各自证据，不替你编造结论。

TURN WORK INTO EXPERIENCE

项目结束后，解决问题的方法还在。

Wayfinder 把目标、尝试、失败和真实文件变更整理成一张本地航海图，让走过的弯路和验证过的方法都能被再次使用。
